# Lightstream / API.stream

> Lightstream (Infiniscene, Inc.) is a Techstars-backed live video company. Its consumer product,
> Lightstream Studio, is a browser-based streaming studio. Its developer platform, API.stream,
> exposes the same cloud video pipeline to partners as three API-first services — a Live API for
> collections, projects, sources, destinations and broadcasts; a Layout API for layered scene
> compositions; and an Event API for real-time pub/sub. All three are defined as gRPC Protobuf
> contracts fronted by gRPC-Web and REST gateways, secured with JWT access tokens and role-based
> permissions.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from apis.yml and the artifacts
in this repository. Lightstream does not publish an llms.txt of its own (probed:
https://api.stream/llms.txt 404, https://golightstream.com/llms.txt is a catch-all redirect).

Key facts an agent should know before calling anything:
- Base URLs: https://live.api.stream/live/v2 (Live), https://live.api.stream/layout/v2 (Layout),
  https://live.api.stream/event/v2 (Event).
- Auth is two-step. The secret API key (`X-API-Key`) may ONLY be used from a backend, and only on
  `BackendAuthenticationService_CreateAccessToken`. Every other call uses
  `Authorization: Bearer <access token>`.
- Updates are PATCH with a protobuf field mask (`updateMask`). REST clients may omit it and the
  gateway computes it from the fields present.
- Errors use the google.rpc.Status envelope (`code`, `message`, `details[]`), not RFC 9457.
- There is NO idempotency key and NO pagination. A 429 means "service busy" — back off exponentially.
- New customer onboarding is currently a waitlist (https://api.stream/).

## APIs
- [API.stream Live API](https://www.api.stream/docs/api/live/rest/): collections, projects, live
  sources (RTMP/SRT/WebRTC), destinations, broadcast start/stop/status/snapshot, WebRTC start/stop,
  access and guest tokens, JWKS.
- [API.stream Layout API](https://www.api.stream/docs/api/layout/rest/): layouts and layers, batch
  layer operations, animation and transitions.
- [API.stream Event API](https://www.api.stream/docs/api/event/rest/): publish and stream events
  scoped to a collection, project or layout.
